# 活色聲香｜TK流行歌唱社（公開版）

- [觀眾投票頁](https://vivid-voices-tk.joyang940309.chatgpt.site)
- [投票管理](https://vivid-voices-tk.joyang940309.chatgpt.site/admin)，後台預設頁。
- [演出管理](https://vivid-voices-tk.joyang940309.chatgpt.site/admin/performance)

Sites 上的公開版使用 Cloudflare D1 儲存票數與 R2 儲存照片、活動備份。管理密碼與 Google Client ID 在 Sites 環境變數設定，勿放進原始碼。推送 GitHub 不會自動發布 Sites。

## 觀眾與管理流程

觀眾 Gmail 登入後，每帳號每輪一票。介面隱藏成績入口，舊 `#scores` 網址也顯示投票頁；保留 `scores()` 程式與入口註解，以便未來重新啟用。`SHOW_PUBLIC_RESULTS` 預設關閉；恢復公開成績時需同時調整後端的公開資料提供，目前不會向觀眾提供票數、勝者或總冠軍。

後台獨立使用管理密碼登入，不提供返回觀眾頁的連結。投票管理可開放、關閉與結算六輪；演出管理可編輯18小組資料、照片與六個演出順位。草莓、檸檬與肉桂使用各自代表色。投票開始後鎖定順序，未開放輪次的小組仍可編輯。

頁面初次載入、登入、登出、票數更新、投票送出、開關投票、統計、順序調整、讀取照片、儲存上傳、總冠軍結算與活動重設皆有載入／處理提示。操作中限制重複送出。開放按鈕為檸檬色、關閉按鈕為草莓色、結算按鈕為肉桂色。

## 總冠軍

全部六輪已結算後，投票管理的「結算總冠軍」按鈕啟用。每輪只有勝利小組的實際票數列入所屬大組；第二、三名不列入。以三大組有效總票數比較，最高者勝利；最高票數相同則顯示並列總冠軍。結果及三組有效總票數只供管理者查看，重複結算不會重複加票。

## 重新開始活動

1. 在投票管理下方按「重設活動」。
2. 選擇「保留隊名、歌曲、成員、照片與順序」（預設），或「全部重新設定為初始小組」。
3. 輸入「重設投票」，按「保存紀錄並重設」。

系統會先關閉投票，將演出、逐輪票數、勝者、總冠軍及匿名投票識別紀錄保存為管理者專用 JSON 備份，成功保存後才清除目前票數與結算。所有輪次回到準備中，觀眾可在下一次開放時重新投票。預設保留全部演出資料；選擇全部重新設定則還原18小組的初始資料與順序。原照片物件保留供紀錄使用。

重設後可展開「已保存的活動紀錄」下載備份。備份屬歷史紀錄；目前沒有自動還原按鈕。備份不公開，也不包含 Gmail 地址與登入憑證。網站更新／發布本身不會執行重設。

## Google 登入

請在 Google Cloud 對應 Client ID 的「已授權 JavaScript 來源」加入 `https://vivid-voices-tk.joyang940309.chatgpt.site`，不含路徑。Gmail 登入用 Google 固定帳號識別碼限制每輪一票，伺服器驗證簽章、有效期、audience、issuer及單次 nonce，無讀信權限。此方式限制帳號數，不能保證每個自然人只持有一個 Gmail。

## 開發與驗證

使用 Node.js 24，`npm run install:ci` 安裝、`npm run build` 建置。按 Sites 技能發布。D1結構由 `db/schema.ts` 與 `drizzle/` 遷移管理；已套用的遷移不可重寫。

`tests/local-event.mjs` 固定只存取 `127.0.0.1:8787`。先在本機套用遷移並使用 `tests/local-fixture.sql` 建立三個測試觀眾，再以本機測試環境執行。測試會在本機建立、結算及重設活動，不可在正式資料庫套用測試 fixture。涵蓋權限、只有勝者計分、重複投票、總冠軍與平手、觀眾結果隱藏、確認文字、兩種重設與私有備份下載。
