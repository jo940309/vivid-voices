# 小成投票網站

繁體中文響應式投票系統，草莓、檸檬、肉桂各六小組，共六輪。原創水彩甜點插畫、手機版面、輕柔進場動畫，支援減少動畫偏好。

## 啟動

安裝 Node.js 24 或更新版本，進入此資料夾後執行 `npm start`，開啟 http://localhost:3000 。無需額外套件。未設定密碼時，啟動畫面會顯示本次隨機管理密碼。

正式部署必須設定環境變數 `ADMIN_PASSWORD` 為長且獨特的管理密碼、`NODE_ENV=production`、`DATA_DIR` 為持久化磁碟路徑。`PORT` 預設 3000。正式版需透過 HTTPS 存取。

## 活動操作

1. 管理後台登入，填寫 18 小組的隊名、歌曲、成員和照片。照片限 PNG/JPEG/WebP、2MB。
2. 各大組使用上下按鈕調整六小組演出順序；同順位自動成為同一輪的三組。
3. 產生並下載專屬投票碼 CSV，每位實際觀眾發放一碼，切勿公開此 CSV。首次登入姓名綁定該碼。
4. 開放指定輪次；系統同時只允許一輪開放，原本開放的輪次會關閉。
5. 觀眾輸入姓名及專屬碼登入，確認投票。伺服器以投票碼與輪次的唯一限制阻止重複投票；換裝置也不能重投。投票碼是持有者憑證，主辦方須避免同一人領取多碼。
6. 按「關閉並統計」結算。勝者票數計入大組，其他票數不計。平手會先關閉投票，再請管理者從平手小組選定勝者。無票不能結算。
7. 六輪完成後，成績頁顯示勝利大組；若最終累計平手，會列出平手大組。

投票開始後不允許修改演出順序，已開放或結算輪次不能修改小組資料。結算後不能重新開放或重複加分。觀眾僅能看到結算後的票數，管理者可查看當前票數。每十秒更新一次。

## GitHub 與公開網址

將此資料夾內容上傳公開 GitHub 儲存庫。這是含後端的完整網站，GitHub Pages 僅支援靜態網頁，無法執行此投票伺服器。

請在支援 Docker、HTTPS 與持久化磁碟的主機連接該 GitHub 儲存庫，使用附帶的 Dockerfile 部署。掛載持久化磁碟至 `/app/data`，設定 `ADMIN_PASSWORD`；主機提供的 HTTPS 網址就是觀眾使用的公開連結。可用自行管理的 VPS 或支援持久磁碟的容器平台。部署單一執行個體；不要使用多台各自獨立的 SQLite 資料庫，也不要使用每次重部署會清空磁碟的配置。

不要把 `data/`、密碼、姓名名單、投票碼 CSV 上傳 GitHub。資料庫含姓名與投票紀錄，活動結束後依主辦方保存需求處理；備份請使用 SQLite 一致性備份工具，避免只複製使用中的主資料庫而漏掉 WAL 資料。

## 驗證

`npm test` 驗證管理權限、18 小組配對、順序調整、姓名綁定、重複投票、關票、僅勝者計分及平手處理。
